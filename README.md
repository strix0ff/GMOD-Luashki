# Касаемо автоотмычки:
 **Внимание! В последнее время администрация начала очень часто отслеживать логи всех взломов на сервере.**

 **К тому же состав разработчиков Noire спустя больше полугода наконец додумался переделать систему логирования и добавить логирование об успешном и не успешном взломе, а так же время которое занимало прохождение "миниигры" отмычки.**

 **Отчёт об успешном взломе:**

 ```
if SERVER then
  DarkRP.log("crime", self:GetOwner(), nil, "взломал отмычкой " .. tostring(ent) .. (ent.McCD_UniqueId and " Номер:" .. ent.McCD_UniqueId or "") .. " за " .. CurTime() - self:GetOwner().lucker[3], nil, nil, self:GetOwner())
end
```

**Отчёт об фейле:**

 ```
ply.lockpick:Fail(true)
ply.lockpick:EmitSound("doors/vent_open1.wav", 50, 200)
DarkRP.log("crime", ply, nil, "неудачная попытка взлома " .. tostring(ent) .. (ent.McCD_UniqueId and " Номер:" .. ent.McCD_UniqueId or ""), nil, nil, ply)
```

***В связи с этим, пожалуйста, соблюдайте следующие рекомендации:***

**1. Не используйте автоотмычку на аккаунтах со слишком маленьким наигранным временем. Администрация сейчас очень строго фильтрует логи и если видит, что подозрительный новичок успешно взламывает всё подряд, то выписывает баны за ES (читы).**

**2. Время от времени намеренно фейлите взлом, дабы не создавать картину идеальных логов для администрации, где вы взламываете всё с первого раза, без единого намёка на промахи.**
